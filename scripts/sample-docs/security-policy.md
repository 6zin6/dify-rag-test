# 情報セキュリティポリシー

## 基本方針
当社は顧客情報・社内情報を適切に保護するため、全従業員がセキュリティポリシーを遵守する義務があります。
違反した場合は就業規則に従い対処します。

## パスワード規則
- 最低12文字以上
- 大文字・小文字・数字・記号を含む
- 90日ごとに変更必須
- 過去5世代のパスワードは再利用禁止
- パスワードマネージャー（1Password）の使用を推奨

## 多要素認証（MFA）
以下のシステムはMFA設定が必須です。
- 社内メール（Google Workspace）
- AWS / GCP
- GitHub
- VPN

## 端末・デバイスの取り扱い
- 社給PCには必ずMDMエージェントをインストール
- 私物PCでの業務システムアクセスは原則禁止
- 画面ロックは5分以内に設定すること
- PCを持ち出す場合は上長に報告が必要

## クラウドストレージ
- 業務データはGoogle Drive（社用アカウント）に保存
- 個人のDropbox・個人Googleアカウントへの業務データ保存は禁止

## インシデント発生時の対応
1. 発見したらすぐにIT部門（it-helpdesk@company.co.jp）へ報告
2. 影響範囲を特定・記録
3. 上長へ報告
4. IT部門の指示に従い対処

## 外部サービス利用
新しいSaaSの導入はIT部門の審査が必要です。
個人判断でのクレジットカード登録・契約は禁止。
