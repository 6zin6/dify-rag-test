# 休暇・勤怠規定

## 所定労働時間
- 勤務時間：9:00〜18:00（休憩1時間）
- 所定労働時間：8時間/日

## フレックスタイム制
コアタイム：11:00〜15:00
フレキシブルタイム：7:00〜11:00 / 15:00〜22:00
1ヶ月の総労働時間を満たせばよい。

## リモートワーク
- 週3日まで在宅勤務可
- 出社必須日：月曜（チームミーティングのため）
- リモート時は9:00までにSlackで「在宅開始」を投稿

## 有給休暇
- 付与タイミング：入社6ヶ月後に10日付与、以降1年ごとに付与
- 取得単位：1日または半日（午前/午後）
- 申請方法：勤怠管理システム（TeamSpirit）で3日前までに申請
- 繰越：最大20日まで翌年に繰越可能

## 特別休暇
| 種類 | 日数 |
|---|---|
| 慶弔休暇（本人結婚） | 5日 |
| 慶弔休暇（忌引き・配偶者） | 3日 |
| 慶弔休暇（忌引き・二親等） | 1日 |
| 産前産後休暇 | 法定通り |
| 育児休業 | 法定通り |

## 残業・深夜勤務
- 残業は事前にSlackで上長承認が必要
- 月45時間を超える残業は原則禁止
- 22:00以降は深夜割増（25%増）が適用されます

## 勤怠の申請・修正
勤怠管理システム（TeamSpirit）を使用します。
打刻漏れ・修正は翌月5日までに申請してください。
